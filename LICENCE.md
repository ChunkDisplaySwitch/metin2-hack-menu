## 🧩 About

**Metin2 Companion** is a curated list of Metin2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap radar, cooldown tracker
- **Quality-of-Life Helpers** — inventory organizer, loot filter, HUD configurator
- **Research Notes** — map and spawn layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Cooldown Tracker — display skill cooldowns on screen
- Minimap Radar — show nearby entities on minimap
- Loot Filter — highlight valuable drops and filter junk
- Auto-Loot Notes — record and review looting patterns
- Movement Speed — adjust walk/run speed for study (0.1x to 5x)

### Wallhack
- Custom HUD — rearrange health, mana, and skill bars
- Inventory Organizer — sort items by category
- Skin Notes — organize character appearance settings
- Chat Filter — highlight important messages

### Aimbot
- Map Markers — add custom waypoints
- Spawn Tracker — note monster spawn locations
- Teleport Notes — record and review teleport points
